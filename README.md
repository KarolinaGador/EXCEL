# Excel Portfolio: Finance & Data Analysis

Four Excel projects, each in its own folder with its own README: a finance tracker with budget planner, report, a salary calculator built on ~32,000 job postings, and a Power Query–based vocabulary tracker.



---

## Projects

| Project | Folder | What it does | Key techniques |
|---|---|---|---|
| **Report** | [`finance-report/`](./finance-report) | A pivot-based dashboard | Pivot tables, pivot charts, timeline slicer |
| **Budget planner and finance tracker** | [`budget-planner-and-finances-tracker/`](./budget-planner-and-finances-tracker) | Yearly finance model + 12-month budget planner| Excel Tables, `SUMIFS`, `XLOOKUP`, Pivot Tables, VBA macro, conditional formatting |
| **Salary Calculator** | [`salary-calculator/`](./salary-calculator) | Median salary for a chosen job title, country and contract type | `XLOOKUP`, data validation, dynamic charts, nested formulas |
| **Chinese Vocabulary Tracker** | [`chinese-vocabulary-tracker/`](./chinese-vocabulary-tracker) | Tracks which HSK1/HSK2 words are learned | Power Query, `COUNTIF`/`COUNTIFS`, conditional formatting |

### Each folder contains the Excel file plus a README explaining what it does and the techniques used.

## Skills 
- **Formulas:** `SUMIFS`, `XLOOKUP`, `IF`, `SEARCH`, `SUBSTITUTE`, `MONTH`, `COUNTIF`/`COUNTIFS`, and more
- **Data import & modelling:** Power Query, Excel Tables, structured references, lookup tables
- **Analysis & reporting:** Pivot Tables, Pivot Charts, timelines, dynamic charts
- **Usability:** data validation (dropdowns), conditional formatting, named ranges
- **Automation:** VBA macro

## Requirements
Microsoft Excel 365 or Excel 2021+ (files use `XLOOKUP`, timelines, Power Query and modern chart types). Enable macros for the Budget Planner.

## Data
Financial data is sample data created for learning purposes. The salary dataset and the HSK word lists are public data.
