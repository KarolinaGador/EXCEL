# Interactive Finance Report

<img width="1250" height="550" alt="image" src="https://github.com/user-attachments/assets/68b2b4db-8c6f-4a1f-8d0a-3529c2e057e5" />


A pivot-based dashboard built on the same transaction data as the [Finance Tracker](../finance-tracker), for a quicker, visual read of income and spending.


## What it does
- 3 Pivot Tables: expenses by category, income and expenses by bank, income by category.
- 3 Pivot Charts on the `report` sheet, built from those Pivot Tables.
- A **date timeline** filter lets you look at any period without touching a single formula.

## Techniques used
- Pivot Tables
- Pivot Charts
- Timeline slicer
