# Data Science Salary Calculator

<img width="1500" height="526" alt="image" src="https://github.com/user-attachments/assets/3a3f403a-31b3-4a6b-bdd5-a93b8fdf2241" />


An interactive calculator built on a public dataset of **32,672 job postings**.

## What it does
- Pick a **job title**, **country** and **contract type** from dropdown lists on the `Basic_Calculator` sheet.
- The median salary for that combination is calculated with `XLOOKUP`.
- The chosen value is highlighted on the chart against all the others.
- Supporting sheets: `Title`, `Type`, `Country`, `Platform`, `Data_Validation`.

## Techniques used
- `XLOOKUP`
- Data validation (dropdowns)
- Named ranges
- Dynamic charts
